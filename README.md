# Causal Actionable Counterfactuals (CAC)

**Black Box → Actionable Insight.** When a model rejects someone, the usual
counterfactual explanation tells them the nearest input that would flip the
decision. That advice can flip the model and still describe a world that could
never come about — it asks for the impossible, or it ignores that changing one
thing changes others. This project separates the three things recourse actually
needs and measures them independently:

- **Valid** — the plan flips the black box *as named*, before the world reacts.
- **Causal** — it still flips the box once a structural causal model propagates
  the declared change into its consequences (replayed-action success).
- **Actionable** — a real person could carry it out.

A plan is **usable** when it is *causal and actionable* — the primary endpoint.
Proposed-state **validity** is reported beside it as the floor the field usually
stops at, and **state fidelity** (how closely a plan's proposed state matches the
one the causal model actually produces) is reported as a separate quality rather
than a gate. Across four public datasets every method we test clears validity, yet
usable recourse ranges from **13% to 100%** — a gap that validity-only evaluation
never sees. **CAC** closes it by searching for an *action* and scoring it through
the causal model, so it can never propose a world its own model disowns.

## Quickstart

```bash
# 1. install (Python >= 3.10; verified on 3.12 and 3.14)
pip install -r requirements.txt          # or: conda env create -f environment.yml

# 2. run the whole deterministic pipeline: data -> models -> results -> figures
make all                                  # or: bash run_all.sh

# 3. build the paper (needs a TeX Live install: pdflatex + bibtex)
make paper                                # writes paper/main.pdf

# 4. explore the results interactively
make app                                  # or: python -m streamlit run app/app.py
```

No paid APIs, no keys, no network calls at evaluation time. Every dataset is
public (fetched via `ucimlrepo`/`kagglehub`), every model runs locally, and the
pipeline is deterministic (`random_state=42`), so `make all` reproduces every
number in the paper.

> **Windows:** run through Git Bash or WSL, and run from the **project root**
> (`cac-blackbox-to-action/`). A stray `src` package elsewhere on `PYTHONPATH`
> can otherwise shadow this project's `src/`; the entry scripts and `run_all.sh`
> guard against this by pinning `PYTHONPATH` to the project root.


The data flow is one-directional: experiments write to `results/`; the notebooks,
the app, the paper tables, and the figures **read** from `results/` and never
recompute. This keeps the demo and notebooks fast and keeps the black box
untouched by anything downstream of training.

## The method, briefly

CAC searches over **actions** — sets of at most three interventions
`do(X_S = v_S)` on features the applicant controls — using a gradient-free
elitist population search. The search is gradient-free by necessity: the black box
is opaque (only `predict`/`predict_proba`), the choice of which features to act on
is a discrete subset selection with no derivative, and the causal model is
piecewise-constant wherever a parent is categorical, so a finite-difference
gradient through it is zero almost everywhere. Each candidate is scored on the
record its structural causal model *produces*, jointly minimising four terms:
validity, effort (cost), feasibility, and plausibility (weights
`1.0 / 0.6 / 0.3 / 0.2`). Because scoring runs through the causal model, causal
validity is structural — a property of the search space — rather than a soft
penalty that can be traded away. See `paper/sections/08_method.tex` and
`src/methods/cac.py`.

## Datasets and black boxes

Adult (income), German Credit, HELOC (home-equity credit), and the Pima diabetes
set. The primary black box is XGBoost, the secondary an MLP; both expose only
`predict` / `predict_proba` — no method inspects trees, gradients, or feature
importances. Held-out performance is in `paper/tables/blackbox_performance.tex`.

## Causal validity without circularity

Scoring a plan only through the same structural model CAC optimises against is a
circular test, so causal validity is audited two further ways the search never
sees:

- **Independent FCM (`experiments/07_decircular_audit.py`).** The structural
  equations are re-fit on a held-out split disjoint from the one the method used,
  and every method's plans are re-scored through that independent model.
- **Known-ground-truth worlds (`experiments/08_known_scm.py`).** Two synthetic
  datasets are generated from fully known structural equations — `synth_reach`,
  where every rejection has a reachable, budget-feasible fix, and `synth_block`,
  where some rejections can only be undone by moving a non-manipulable ancestor —
  and declared actions are replayed through the exact analytic SCM.

Usable rate is therefore reported under the **specified** SCM, an **independent**
FCM, and the **true** SCM. CAC and the cost-optimal causal baseline **MINT**
(minimal-cost causal intervention, scored by identical cost accounting) are
expected to fall below perfect causal validity under an auditor they did not
optimise against — that lower number is the honest one, and `synth_block` keeps
the genuinely unreachable cases visible instead of papering over them.

## Statistical validity

Headline rates come from a stochastic search, so `experiments/06_significance.py`
repeats the whole comparison across five seeds
(`SIGNIFICANCE_SEEDS = 42, 0, 1, 2, 3`). Two different questions are kept apart:

- **Does the optimiser wobble?** Each rate's mean with a 95% Student-*t* interval
  over the five seeds measures search/seed stability — not applicant uncertainty —
  and `paper/tables/significance.tex` is captioned as such.
- **Is CAC better per applicant?** Significance is tested at the level of the
  **applicant**, the unit that actually generalises. The paired **exact McNemar
  test** compares one prespecified usable/not-usable outcome per applicant at the
  canonical seed (42); the usable-rate gap is sized by a **cluster bootstrap** over
  applicants (each applicant's mean rate across the seeds), so repeating identical
  seeds can no longer inflate significance. The baseline family per dataset is
  corrected with **Holm's step-down** rule, in
  `paper/tables/significance_tests.tex`.

This study is part of the reproducible build — `make all` and `run_all.sh` run it,
and `make significance` runs it on its own. The run is resumable — it appends
per-seed rows to `results/significance_runs.csv` and skips cells already on disk —
so it can also be run dataset by dataset.

## Design decisions and scope

Some choices are worth stating explicitly, either because a reader might expect a
different default or because they bound what the results claim.

1. **The search operators are a design choice, not a tuned optimum.** The
   objective (four terms, their weights, and intervention-through-SCM scoring) is
   the substance; the specific operators (elitist population, crossover, Gaussian
   jitter, set mutation, legalisation) are the standard toolkit for a mixed
   discrete–continuous space, and none of the claims depend on the search finding
   a global optimum — only on the representation, which makes a causally
   impossible plan un-scoreable. Rationale in `paper/sections/08_method.tex`.
2. **Four datasets, including Pima diabetes.** The diabetes label is inverted so
   the favourable class is *no diabetes* (`no_diabetes = 1 - Outcome`), and a
   class-conditional imputation that would have leaked the label into `Insulin`
   and `SkinThickness` is removed before the split (`src/data/load_diabetes.py`).
3. **The Adult SCM has 10 nodes and 25 edges**, chosen so the target is reachable
   from the actionable set through realistic mediators.
4. **The German and HELOC graphs are imperfect, and reported as such.** Credit
   features are densely inter-correlated; a parsimonious hand-drawn graph omits
   real dependences (German supports 18/37 asserted edges, HELOC 18/28). We keep
   the graphs rather than densifying them to pass the tests, report the validation
   in full (`paper/tables/scm_validation.tex`, appendix), and show under graph
   perturbation that CAC degrades gracefully rather than depending on a perfect
   graph.
5. **Per-record, not per-suggestion, headline rates.** A method is credited on a
   record if *any* of its `k=5` suggestions is usable (a person needs one plan they
   can follow). Per-suggestion audits are retained for the appendix and ablation.
6. **Two cost-ratio definitions.** Cost is reported both against the cheapest
   *oracle* flip on the same record (`Cost/Oracle`, main table) and against CAC's
   own full objective (`Cost/CAC`, ablation). Both appear because they answer
   different questions; captions state which is which.
7. **The budget is derived, not hard-coded.** The normalising budget is the summed
   cost of a dataset's three most expensive admissible actions (§7.2), computed per
   dataset.
8. **`LevelEncoder`, not `LabelEncoder`.** Ordinal features use a custom
   level-aware encoder that preserves order and admissible direction.
9. **Two-space representation.** The pipeline keeps a raw feature view and an
   encoded view with explicit `encoded_bounds`, so the SCM and the cost model can
   each work in the space natural to them.
10. **Streamlit for the demo.** The interactive explorer over the stored results
    is built with Streamlit.
11. **Notebooks shipped unexecuted.** No Jupyter kernel is installed in the build
    environment, so the four notebooks ship with empty outputs; their code is
    smoke-tested as scripts. Run them locally to populate outputs.

## User study

`user_study/` ships a **protocol**, not collected data: an ethics checklist and
consent form (`consent.md`), the instrument (`questionnaire.md`), and an analysis
script (`analysis.py`). With no real responses, `analysis.py` generates a
deterministic, honest-by-construction **synthetic** response set so the analysis
runs end to end; point it at a real CSV with `--responses` to analyse a real
study. The synthetic responses are a demonstration of the pipeline, not evidence,
and the generated table's caption says so.
